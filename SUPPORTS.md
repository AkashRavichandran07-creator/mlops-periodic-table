# Support

Thank you for your interest in the **MLOps & MLSecOps Periodic Table**
project!

The **MLOps & MLSecOps Periodic Table** is an open-source educational
resource that presents the MLOps and MLSecOps ecosystem in an
interactive, periodic table-inspired format. Each tool includes a
concise description, its purpose, primary use cases, and links to
official documentation, making it easier for learners, practitioners,
and researchers to explore the modern AI operations and security
landscape.

## Getting Help

If you have questions about the project, need clarification, or want
guidance on using or contributing to the repository, please:

-   Search the existing GitHub Issues.
-   Check the project README for documentation.
-   Open a new Discussion (if enabled) for general questions.
-   Create a new Issue if you believe you've found a bug or
    documentation problem.

## Reporting Bugs

When reporting a bug, please include:

-   A clear description of the issue.
-   Steps to reproduce it.
-   Expected behavior.
-   Actual behavior.
-   Screenshots (if applicable).
-   Browser and operating system.
-   Any relevant console errors.

## Suggesting New Tools

We welcome suggestions for new MLOps and MLSecOps tools. Please include:

-   Tool name
-   Official website or repository
-   Category
-   Short description
-   Primary use case
-   License (if known)

## Improving Content

Contributions are welcome for:

-   Tool descriptions
-   New tool additions
-   Documentation improvements
-   UI/UX enhancements
-   Accessibility
-   Performance optimizations
-   GitHub Pages compatibility

## Supported Versions

  Version              Supported
  ------------------- -----------
  Latest (main)           ✅
  Previous releases       ❌

## Security Issues

If you discover a security vulnerability affecting this repository
itself (not a listed tool), please report it privately to the
maintainers instead of opening a public issue.

## Contributing

We welcome contributions from developers, MLOps engineers, ML security
researchers, DevSecOps professionals, students, educators, and the
open-source community.

Every contribution---whether it's adding a new tool, improving
documentation, refining the interface, or fixing bugs---helps make this
project a valuable learning resource for everyone.

Thank you for supporting the **MLOps & MLSecOps Periodic Table**
project!
